# Driver-Drowsiness-Eye-Detection
A deep learning-based system for detecting driver drowsiness using YOLO11n.
## Overview
This project detects eye and mouth states from driver images and videos to identify potential signs of drowsiness.
The YOLO11n model is trained to detect four classes:
- `eye_open`
- `eye_closed`
- `mouth_open`
- `mouth_closed`

## Project Pipeline
1. Data Annotation
2. YOLO11n Model Training
3. Model Evaluation
4. Image Testing
5. Video Testing
6. Drowsiness Detection
7. Real-time Detection

## Technologies
- Python
- YOLO11n
- Ultralytics
- OpenCV
- Deep Learning
- Object Detection

## Goal
The goal of this project is to develop a real-time driver monitoring system that can detect signs of drowsiness and provide warnings to improve driving safety.
